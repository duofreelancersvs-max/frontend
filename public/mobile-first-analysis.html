📱 ProdMatch Mobile Layout (from live UI)

The logged-in ProdMatch dashboard (see your screenshot) follows a three-zone mobile shell:

  • Sticky top bar (~44–56px) — hamburger, logo, usage pill, search & notifications. No large page title.
  • Scrollable content — greeting, status strip, one hero CTA card, 2×2 metric grid. Tight 12–16px margins.
  • Fixed bottom nav — exactly 5 tabs: Home · Matches · Apps · DSA · Profile. Icon + 10px label. Active tab in brand blue.

Secondary destinations (settings, filters, legal) stay in the hamburger drawer — not in the bottom bar. This matches industry guidance: 3–5 thumb-reachable primary destinations only.

⚙️ Implementation Flow in ConnectMeIndia

1. Layout shell (ClientLayout / FreelancerLayout) Full viewport height, scrollable main column, bottom padding reserved for nav bar.
2. Bottom navigation (BottomNav.tsx) Rendered only below lg. Reads items from navigation.ts. Active state + message badges.
3. Compact header (DashboardHeader.tsx) Mobile: hamburger + logo + search/messages. Desktop: full title + theme toggle + profile.
4. Page content (.dashboard-content utilities) All dashboard pages use shared spacing classes instead of ad-hoc px-6 py-6.
5. Progressive disclosure Floating chat hidden on mobile (Messages is in bottom nav). Sidebar holds infrequent routes.

📚 Industry Best Practices (Web Research)

ProdMatch aligns with established mobile dashboard patterns cited by UX research:

  • Rule of 3–5 tabs — Bottom bar should not exceed 5 destinations; more items go in drawer/menu. (Superfiles, UXPin)
  • Always pair icons with labels — 10–12px text under each icon; icons alone fail accessibility. (Superfiles)
  • Thumb zone placement — Primary actions in bottom 40% of screen; avoid top-corner critical actions. (UXPin)
  • Progressive disclosure — Show metrics & CTA first; secondary details in expandable sections or kebab menus. (Querio)
  • Hybrid navigation — Bottom tabs for top-level + hamburger for secondary (Spotify, Gmail pattern). (UXPin)

✅ Remaining Enhancements (Optional)

  • Usage pill in header — ProdMatch shows "Free 0/5" in the top bar; freelancers already have UsageIndicator in sidebar — could surface on mobile header.
  • Hide bottom nav on scroll down — Reveal on scroll up for feed-style pages.
